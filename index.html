Questions

Are these really free?

Yes. Every tool is free to install and use. If a heavier AI feature ever needs a paid plan, it'll be clearly marked, the core job stays free.

Do you send my data anywhere?

As little as possible. Most work happens right in your browser. When a task needs a server, the file is streamed, processed and dropped, never stored on our side and never sold. Each tool's page spells out exactly what it does.

Do I need an account?

No. There's no sign-up, no login and no email required. Add the extension and start using it.

Which browsers are supported?

Any Chromium browser, Chrome, Edge, Brave, Opera and others, installs the extensions from the Chrome Web Store.

Are more tools coming?

Yes. Four extensions are live already and the lineup keeps growing. Same rules every time: small, private, no sign-up.
