# Off-page: что реально работает у мейкеров (ресёрч 28.09.2026)

Источники: Indie Hackers, dev.to, HN, блоги. Reddit агенту закрыт (403), прямых цитат оттуда нет.
rel проверен curl-ом только у dev.to (dofollow в теле статьи) и GitHub README (nofollow). Остальное = не проверено.

Топ по (доказательность × подходит нам × дёшево):
1. Бесплатные веб-инструменты на своём домене (PDF/картинки) + CTA на расширение. Кейс QuickTools.one: 11 инструментов, 4 нед, 100+ визитов/день, 71% трафика из ChatGPT. https://dev.to/eduard_albu/building-boring-tools-that-rank-4-weeks-11-tools-and-a-plot-twist-with-chatgpt-304
2. SEO карточки CWS + блог «[задача] extension» (Web Highlights 100K). Не бэклинк, органика.
3. Ручной outreach авторам нишевых «best X tools» (реально 8-15% ответов, 1-2% включений). По bank statement обзоры пишут конкуренты, шансы низкие.
4. dev.to с canonical на наш сайт: ссылки в теле dofollow (проверено). Medium nofollow/ugc (проверено 10.10 на нашей статье: rel="noopener ugc nofollow").
5. Нишевые каталоги / alternative-to: кейс iOS 15 каталогов = 4 dofollow, DR 5→8.
6. Source of Sources (free), Qwoted 2/мес, Featured 3/мес: только темы экспертизы (OCR, выписки). Статистики нет.
7. Свои данные как магнит (напр. точность OCR на выписках разных банков). Единичный кейс.

Не работает: README/awesome-lists (nofollow), холодные письма без персонализации, Show HN как ссылка (nofollow), Quora/SO (nofollow), списки 100+ каталогов, покупка.
Сроки: ссылки 4-8 нед, органика нового домена 3-6 мес.
