# Product Hunt — жёсткие правила запуска (Денис, 2026-08-06)

## День запуска = ВСЕГДА ПЯТНИЦА
НЕ вторник/среда (это generic-совет для крупных продуктов, для нас ВРЕДЕН).
Причина: мы микро-приложения, конкурировать за охват с хайповыми запусками не можем.
Хайп валит в высококонкурентные дни (вт-ср). В пятницу конкуренция минимальна →
наш шанс попасть в лидеры дня. ЧЕМ МЕНЬШЕ КОНКУРЕНЦИИ, ТЕМ ЛУЧШЕ. Не путать.

## Аккаунт = прогретый личный аккаунт Дениса
НЕ team@/новый. У прогретого аккаунта растёт network (взаимные upvote, фолловеры) с
каждым запуском. Новый аккаунт летом — фолловеров ноль, охвата ноль.
