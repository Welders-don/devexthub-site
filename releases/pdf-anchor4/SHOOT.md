# Съёмка PDF #4 (pdf to csv), формат ~2.5 мин 16:9 — сценарий для Дениса

Excel НЕ открываем вообще. Кадры «вставил в таблицу → одна колонка» и «открыл CSV → ровные
колонки» рисую я сам из реального CSV, который скачаешь на съёмке (моки mock/paste.png, mock/csv.png).
Снимаешь только Chrome.

## Подготовка (5 мин, один раз)
1. Chrome на английский: Settings → Languages → Russian «…» → убрать / English наверх →
   «Display Google Chrome in this language» → Relaunch. Расширение у нас переведено на 50 языков,
   при русском Chrome панель будет русской. После съёмки вернуть обратно так же.
2. Новый профиль Chrome «Demo» (аватар справа вверху → Add): чистый тулбар, без имени и закладок.
3. Файл bank-statement-sample.pdf (пришлю) положить на рабочий стол.
4. OBS: источник «Захват окна» → Chrome, 1920x1080. Панель задач Windows в кадр не попадает.
5. Масштаб страницы 100%, окно Chrome развернуть на весь экран.

## Дубль 1. Установка (~30 с)
Профиль Demo → открыть карточку PDF to Excel в Chrome Web Store → Add to Chrome → Add extension
→ пазл справа вверху → булавка у PDF to Excel. Иконка встала в тулбар. Стоп.

## Дубль 2. Основной флоу (~60 с)
1. Перетащить bank-statement-sample.pdf в Chrome, открылся PDF. Пролистать вниз-вверх (3 с).
2. Клик по иконке → выехала боковая панель. Пауза 2 с.
3. Перетащить тот же PDF с рабочего стола в панель (или Choose file).
4. Convert → дождаться таблицы в панели, медленно прокрутить её (3-4 с).
5. Download .csv → внизу/сверху появилась загрузка. Пауза 2 с.
6. Download Excel (.xlsx) тоже, для кадра «оба формата». Стоп.

## Правила записи
[x] Мышь медленно, после каждого клика пауза 1-2 с. Промахи и паузы вырежу сам.
[x] Каждый дубль снять 2 раза, выбираю лучший.
[x] Ничего личного в кадре: только профиль Demo.
[x] Прислать: оба видео + скачанный .csv (из него рисую кадр результата).
