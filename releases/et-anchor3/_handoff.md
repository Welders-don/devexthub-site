## Что сделано
1. **Футаж пришёл** от Дениса zip'ом `compross_ru_files (14).zip` = `compressed_2026-09-14_11-36-27.mp4`
   (82.2с, 1920x1080, 30fps). Флоу Upload File на `demo-invoice.jpg` (NORTHGATE SUPPLIES, TOTAL DUE 310.12).
   Звук футажа НЕ используется (посторонний, кладём свой).
2. **Разметка футажа** (нелинейный кадр, титр = то, что в кадре — верифицировано по кадрам финала):
   - попап ПУСТОЙ (Upload File + Choose file + Processing...) ~26-30с
   - попап РЕЗУЛЬТАТ (весь текст счёта + Copy all/Download) ~30-35с
   - счёт крупно в просмотрщике ~40-55с
   - сравнение: счёт слева + скачанный extracted-text.txt в Notepad справа ~72-80с
3. **Приватность:** аватар профиля «N» и личные ярлыки нового таба (MERCENAIRE, Search Internship,
   An interview with…) в кадр НЕ попали — тесные кропы на UI их отрезают (заодно читаемость).
4. **Голос Kore** (`gen_voice.py`, gemini-2.5-flash-preview-tts), 24.24с, loudnorm I=-14, старт на 2.0с.
5. **Сабы Groq** whisper-large-v3 пословно (`groq_words.json` → `make_subs.py` → `subs.srt`),
   OFF=2.0. Правка: Groq услышал «JPEG» → в сабах заменено на «JPG» (консистентность с тайтлом).
6. **Сборка** `build_et_anchor3.sh`: 6 сегментов (2 карточки + 4 плана), титры, concat -c copy →
   mute-мастер, затем прожиг сабов + наложение голоса одним проходом → final.
