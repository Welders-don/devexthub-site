How to save an Excel file as a PDF

Convert PDF to Excel · 4 min read

You need to send a spreadsheet as a PDF, so it opens the same on any device and nobody edits the numbers by accident. Here is how to save an Excel file, XLSX or XLS, as a clean PDF in one click, without the columns spilling onto extra pages.

Saving to PDF sounds like a one-liner, and sometimes it is. But the moment a sheet is a little wide, Excel prints it at full size and your neat table splits across three pages, with two lonely columns marooned on the last one. The trick is fitting the sheet to the page before it becomes a PDF.

Option 1: straight from Excel

Excel can do this itself: File → Save As (or Export) and choose PDF. It works, but check the print settings first. Open Page Layout and set Width to 1 page under Scale to Fit, otherwise wide sheets overflow. On a small or shared machine without Excel installed, this route is not available at all.

Option 2: one click in the browser

Convert PDF to Excel is a free Chrome extension that also goes the other way, turning an Excel file into a clean PDF right in your browser, no desktop Excel needed.

  1. Add the extension to Chrome.
  2. Open or drop in your .xlsx or .xls file.
  3. Export as PDF. The sheet is fitted to the page width so columns stay together.
  4. Download a fixed PDF that looks identical on any screen.

XLSX or XLS: does it matter?

No. XLSX is the modern format and XLS is the older one, but both save to PDF the same way and give the same fixed output. If a colleague sends you an ancient .xls, you do not need to convert it first.

Why send a PDF at all?

A PDF locks the layout: the recipient sees the same rows, columns and totals you did, on any device, and cannot nudge a formula by accident. That is why invoices, reports and price lists travel as PDF even when they were born in Excel.
