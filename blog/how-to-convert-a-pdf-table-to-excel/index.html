How to convert a PDF table to Excel

Convert PDF to Excel · 4 min read

You've got a table trapped in a PDF, an invoice, a bank statement, a report, and you need it in Excel to actually work with the numbers. Here's how to pull it out cleanly in one click, with the columns and totals intact.

Copy-pasting a PDF table into Excel almost never works: the columns collapse into one, the numbers turn into text you can't sum, and you spend ten minutes re-splitting cells by hand. The fix is a tool that reads the table's structure and rebuilds it properly.

The fastest way: a one-click Chrome extension

Convert PDF to Excel is a free Chrome extension that extracts the table from the PDF you're viewing into a clean, editable sheet, right in your browser.

  1. Add the extension to Chrome and open your PDF.
  2. Click the extension icon. It finds the table and rebuilds it column by column.
  3. Download a clean .xlsx or CSV file, with rows, columns and totals in the right place.
  4. Numbers come out as real numbers you can add up, not text.

Why the numbers matter

The whole point of getting a table into Excel is to calculate with it. When numbers arrive as text, your formulas break and totals read as zero. This extension keeps numbers as numbers, so 1,488.00 is a value you can sum, not a string you have to clean up first.

What about scanned or photographed PDFs?

Text-based PDFs convert for free. If your PDF is a scan or an image-only file, like a photographed invoice, an optional AI mode reads it too. It's opt-in, so you choose when to use it, and plain text PDFs never need it.
